Lantai 4 Gedung Tower didesain khusus sebagai zona steril terintegrasi satu atap untuk seluruh tindakan perawatan intensif rumah sakit. Menggabungkan penanganan komprehensif kardiovaskular, pasca-bedah mayor, serta resusitasi neonatal dalam perimeter monitoring 24 jam dengan tekanan udara negatif dan filtrasi HEPA terkontrol.
