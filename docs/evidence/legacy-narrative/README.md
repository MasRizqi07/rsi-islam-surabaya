# Arsip Ringkasan Naratif (Legacy Narrative)

Direktori ini hanya memuat berkas ringkasan naratif (`phase-*.json`) buatan agent pada fase sebelumnya. Berkas-berkas ini adalah ringkasan naratif, bukan bukti output terminal mentah (*raw evidence*). Jangan dikutip sebagai bukti verifikasi teknis. Bukti mentah tersimpan di `docs/evidence/raw/`.
