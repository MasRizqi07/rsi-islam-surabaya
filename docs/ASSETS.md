# Register Aset Visual & Status Hak Cipta

Dokumen ini mencatat seluruh aset gambar, logo, dan foto resmi yang digunakan dalam studi kasus portofolio independen **RS Islam Surabaya A. Yani (Konsep Hijau Tower)**.

## Kebijakan Penggunaan Aset
Sesuai arahan arsitektur proyek:
1. Seluruh logo dan foto resmi gedung rumah sakit dipasang atas keputusan eksplisit **Pacoel**.
2. Logo resmi hanya ditampilkan maksimal satu kali per layar tampilan untuk mencegah redundansi visual.
3. Favicon dan Open Graph (OG) image tetap menggunakan identitas siluet geometris Hijau Tower karya mandiri, bukan logo rumah sakit.
4. Pada header di seluruh halaman website, disematkan badge penanda **"Demo Portofolio"** untuk mempertegas sifat non-resmi dari studi kasus teknologi ini.
